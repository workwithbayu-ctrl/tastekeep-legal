Kebijakan Privasi

Terakhir diperbarui: 25 Agustus 2026

Ringkasan

Tastekeep membantu Anda menyimpan dan menggunakan resep secara lokal. Kami tidak menggunakan behavioral analytics untuk melacak cara Anda memakai aplikasi.

Data yang diproses

Data fitur Tastekeep—misalnya resep, pantry, daftar belanja, profil keluarga, catatan memasak, dan katalog bahan—disimpan secara lokal pada perangkat menggunakan SwiftData agar tetap berguna saat offline.

Secret Ingredients Vault menyimpan konten rahasia secara lokal di Keychain perangkat. Konten tersebut memerlukan autentikasi perangkat untuk dibuka dan tidak dirancang untuk muncul saat vault terkunci.

Autentikasi

Tastekeep menggunakan Google Sign-In dan Firebase Authentication untuk autentikasi. Informasi akun digunakan untuk menjalankan sesi autentikasi. Tastekeep saat ini tidak menyatakan bahwa data fitur lokal telah disinkronkan ke Cloud Firestore atau Cloud Storage.

Impor URL resep

Jika Anda memasukkan URL resep, Tastekeep memproses URL yang Anda masukkan untuk membantu menyiapkan preview resep. URL sumber disimpan sebagai atribusi pada resep yang Anda simpan. Jangan masukkan URL yang tidak ingin Anda proses di aplikasi.

Penyimpanan dan penghapusan

Data lokal berada pada perangkat Anda sampai Anda menghapusnya melalui aplikasi atau menghapus akun. Penghapusan akun bersifat permanen dan menghapus akun Firebase Authentication, seluruh data lokal Tastekeep, serta entri Secret Ingredients Vault di Keychain pada perangkat.

Baca instruksi penghapusan akun.

Perubahan kebijakan

Kebijakan ini dapat diperbarui apabila implementasi Tastekeep berubah. Tanggal pembaruan akan diperbarui pada halaman ini.
